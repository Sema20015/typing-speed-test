## Обзор

### Задача

Пользователи должны иметь возможность:

- Видеть оптимальное отображение интерфейса в зависимости от размера экрана устройства.
- Видеть состояния наведения курсора и фокуса для всех интерактивных элементов страницы.

### Скриншот

![Скриншот проекта](./screenshot.jpg)

Добавьте скриншот своего проекта. Самый простой способ — открыть сайт в Firefox, нажать правой кнопкой мыши на страницу и выбрать «Сделать снимок экрана». Можно сделать скриншот всей страницы или только её части.

Также можно воспользоваться программой [FireShot](https://getfireshot.com/). У неё есть бесплатная версия.

После этого обрежьте, оптимизируйте или отредактируйте изображение, добавьте его в проект и укажите правильный путь к файлу выше.

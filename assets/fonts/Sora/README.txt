# Переменный шрифт Sora (Sora Variable Font)

Этот архив содержит шрифт Sora в двух вариантах: переменный шрифт и статические шрифты.

Sora — это переменный шрифт с одной осью настройки:

- `wght` — толщина начертания (вес шрифта).

Это означает, что все варианты толщины содержатся в одном файле:

`Sora-VariableFont_wght.ttf`

Если приложение полностью поддерживает переменные шрифты, ты можешь выбирать промежуточные значения толщины, которые недоступны в статических версиях.

Не все приложения поддерживают переменные шрифты. В таком случае можно использовать отдельные статические файлы Sora:

- `static/Sora-Regular.ttf` — обычное начертание.
- `static/Sora-SemiBold.ttf` — полужирное начертание.
- `static/Sora-Bold.ttf` — жирное начертание.

## Начало работы

1. Установи необходимые файлы шрифта.
2. Открой список шрифтов в своём приложении и найди семейство Sora со всеми доступными начертаниями.
